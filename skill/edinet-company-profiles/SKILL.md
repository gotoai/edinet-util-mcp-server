# EDINET 企業プロファイル

EDINET の有価証券報告書から作った、上場企業のデータベースと、それを引くスクリプトです。
データは読み取り専用で、スナップショット時点（`about` で確認）までのものです。

- **このスキル**：会社を探す、プロファイルと5年分の数値、同業候補、指標の比較、書類管理番号。
- **edinet-util（MCPサーバー）**：書類そのものを読む（`export_filing`）、スナップショット後の提出を
  探す（`list_filings`）。本文や、データベースにない数値（有利子負債、設備投資、研究開発費、
  セグメント別）はこちらで読みます。

同業比較や財務診断を頼まれたら、まずスキルのフォルダの `references/financial_diagnosis.md` を
読んでください（ファイルを読むツールがなければ、python_run で開いて print します）。

## 使い方

Kari では python_run で、スキルのフォルダ（読み込み時に表示される Skill directory）の
スクリプトを呼びます。

```python
import runpy
profiles = runpy.run_path("<Skill directory>/scripts/edinet_profiles.py")
status, text = profiles["run"](["compare", "7203"])
print(text)
```

シェルが使える環境では `python scripts/edinet_profiles.py compare 7203` でも同じです。
標準ライブラリだけで動きます。

| コマンド | 返すもの |
|---|---|
| `company <会社>` | プロファイル（証券コード、業種、市場、決算日、会計基準）と5年分の数値 |
| `peers <会社> [-n 10]` | 同業候補（同じ東証33業種で、規模と事業内容の文章が近い順。スコアと理由つき） |
| `compare <会社> [--peers "A,B"] [-n 5]` | 対象と同業他社の指標表、同業中央値・差・順位、推移、注記、各社の有価証券報告書の書類管理番号 |
| `filings <会社> [--types 120,160] [--limit 30]` | 提出書類の一覧と書類管理番号（120 有価証券報告書、160 半期報告書、180 臨時報告書） |
| `sql "SELECT …"` | 上で足りないときの読み取り専用クエリ（表と列は `about` に） |
| `about` | スナップショットの時点、件数、出所、表と列 |

- `<会社>` は証券コード（7203、7203.T、72030）、EDINETコード（E02144）、社名の一部（漢字・カナ・
  英語）のどれでも構いません。候補が複数あると一覧を返すので、コードで選び直してください。
- `--json` をつけると構造化データで返ります。
- `compare --peers` には利用者が挙げた同業他社を渡します。足りない分は同業候補の上位から順に
  補います（`-n` は対象を除いた比較企業の数で、既定は5社）。比較できない会社は理由つきで「外した企業」に出ます。

## 数値の読み方

- 金額は円、比率は小数で保存しています（表示は百万円・%）。各社の最新期どうしの比較で、
  決算期が違えば注記に出ます。
- `sec_code` は EDINET の5桁（先頭4桁が普段の証券コード）です。表示は4桁にしてください。
- 状態が `ok` 以外の会社（3期未満、有価証券報告書なし、CSVなし）は数値と同業候補がありません。
  理由は `company` が示します。
- スナップショットより後に提出された書類は入っていません。新しい決算が出ていそうなときは
  `list_filings` で確かめます。

## 出典の表示（必ず守ってください）

スクリプトの出力の末尾に、出典・加工の表示・データ時点が付いています。この数値を使って
回答や資料を作るときは、次の2行とデータ時点を必ず添えてください。加工したデータを、
加工していない政府のデータであるかのように示してはいけません。

- 出典：EDINET閲覧（提出）サイト（https://disclosure2.edinet-fsa.go.jp/）、PDL1.0（https://www.digital.go.jp/resources/open_data/public_data_license_v1.0）
- EDINET閲覧（提出）サイトの提出書類をもとに GotoAI が加工して作成
